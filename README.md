 Netflix Data Analysis Project

## 📌 Project Overview
Analyzed Netflix movies and TV shows dataset to find insights on content trends, ratings, genres, and country-wise distribution using Excel and Power BI.

## 🛠️ Tools & Technologies Used
- Microsoft Excel (Data Cleaning, Pivot Tables)
- Power BI (Data Visualization & Dashboard)
- Data Analysis & Cleaning

## 📊 Key Insights
- Analyzed 8000+ titles of Movies and TV Shows
- Top 5 countries producing most Netflix content
- Most common genre and rating analysis
- Year-wise content addition trend
- Movies vs TV Shows comparison

## 📈 Dashboard
Power BI interactive dashboard showing genre distribution, content by country, and ratings.

- Netflix Dataset (CSV)

- Power BI Dashboard (.pbix)
- Dashboard Screenshots
